Part 1 · Notes I.1

Truth tables and Venn diagrams

Logic and set theory are one algebra written two ways: ∧ is ∩, ∨ is ∪, ¬ is the complement. Pick two statements; the lab builds both truth tables and shades both Venn diagrams. If the last column is 1 in every row, the two statements are equivalent.

Shaded means the statement is true there. Each of the four regions of a diagram is one row of the table: point at a region to light up its row. The part of the universe X outside both circles is the row A = 0, B = 0.

Try this. Compare “Contrapositive” with “Converse”. The contrapositive matches A ⇒ B row for row. The converse differs in the two rows where A and B disagree. “If it rains, the street is wet” does not mean “if the street is wet, it rained”.

Key facts

  • A ⇒ B is false only in the row A = 1, B = 0. A false premise makes the implication true. [I.1.1]
  • A ⇒ B ⇔ ¬A ∨ B ⇔ ¬B ⇒ ¬A. The converse B ⇒ A is a different statement.
  • De Morgan: negating swaps ∧ and ∨, so ¬(A ∧ B) ⇔ ¬A ∨ ¬B. For sets, (A ∩ B)ᶜ = Aᶜ ∪ Bᶜ. [Thm 1.4, 1.13]
  • ∨ is inclusive: “A or B” is also true when both hold.
Part 2 · Notes I.2.2

Absolute-value inequalities

|u| is the distance of u from 0. So |mx + c| ≤ r asks for every x whose value mx + c lies within r of zero. The graph of |mx + c| is a V with its kink where the inside is zero. On each side of the kink it is a straight line, which is why the case split works.

The V is the graph of |mx + c|, the horizontal line is y = r. The shaded band and the thick bar on the x axis show the solution set. A filled endpoint belongs to the set, a hollow one does not. The default is the notes' example |x + 3| ≤ 5.

Try this. Drag r below zero. “≤” now has no solution and “≥” holds for every x, because |u| ≥ 0 always. Then set m = −1 and c = −3: the set is the same as for |x + 3|, since |−u| = |u|.

Key facts

  • Method: split where the inside changes sign, solve the linear inequality on each side, keep only solutions on that side, then combine. [I.2.2]
  • |x − a| ≤ r means all x within distance r of a: the interval [a − r, a + r]. |x − a| ≥ r gives the two outer rays.
  • |u| ≥ 0, so |u| ≤ r with r < 0 has no solution.
  • Squaring both sides is not an equivalence transformation; check every candidate.
Part 3 · Notes I.2.4

Induction: Bernoulli's inequality

Induction proves a statement for every n with two moves: a base case and a step from n to n + 1. Bernoulli's inequality is the course's model proof. Watch where the step needs x ≥ −1.

(1 + x)n ≥ 1 + nx for all n ∈ ℕ and x ≥ −1Theorem 2.15. The notes extend it to x ≥ −2 in Theorem 2.17.

The dominoes: does the inequality hold at this x for n = 1, 2, …?

Curve: (1 + x)n. Straight line: 1 + nx, its tangent at x = 0. Shaded bands mark where the inequality fails. The vertical bar at the probe connects the two values.

Try this. Set n = 3 and move x below −2. Around x = −3 the curve dips under the line: the inequality really fails there. For x between −2 and −1 it still holds, although the notes' first proof does not cover it.

Key facts

  • Write all three parts: base case, induction hypothesis, induction step n → n + 1. [I.2.4]
  • The step multiplies the hypothesis by 1 + x. That keeps “≥” only if 1 + x ≥ 0, hence x ≥ −1.
  • Variants: base case at n₀, or several base cases with a step n → n + 2 (Theorem 2.17).
  • Use it for quick bounds: (1 + π/10)100 ≥ 1 + 31.4 = 32.4.
Part 4 · Notes I.3.1–I.3.3

Injective, surjective, bijective

A function is a rule together with its domain D and codomain Y. Change only the domain or the codomain and the same rule can gain or lose injectivity and surjectivity. The horizontal line y = c tests both at once: count how often it meets the graph.

Solid graph: the function on its domain. Dashed grey: the same rule outside the domain, which no longer counts. Bottom strip: the domain. Left strips: the codomain Y (outer) and the range W(f) (inner). Drag the dashed horizontal line.

Try this. Start with x² on ℝ → ℝ and make it bijective in two clicks: restrict the domain to [0, ∞), then shrink the codomain to the range. Now the inverse √y appears as the mirror image across y = x.

Key facts

  • Injective: different inputs, different outputs. Every horizontal line meets the graph at most once. Strictly monotone implies injective. [Def 3.3]
  • Surjective: W(f) = Y. Every horizontal line at a height in Y meets the graph at least once.
  • Injectivity depends only on the graph; surjectivity depends on the codomain.
  • Bijective functions have an inverse; domain and range swap, and the graph reflects across y = x. [I.3.3]
Part 5 · Notes I.3.6, I.4.1

Complex numbers in the Gaussian plane

A complex number is a point: z = a + ib sits at (a, b), at distance r = |z| from 0 and at angle φ = arg z. Adding works coordinate by coordinate. Multiplying multiplies the lengths and adds the angles, which normal form hides and polar form shows.

z = a + ib = r(cos φ + i sin φ) = reiφr = √(a² + b²); φ from arctan(b/a) plus a quadrant correction, so that φ ∈ [0, 2π).

Drag z and w. The thick arrow is the result. Arcs mark the angles measured from the positive real axis; the dashed circle is the unit circle.

Try this. In polar form, drag z into the second quadrant (a < 0). arctan(b/a) alone now points into the opposite quadrant, which is why the notes add π. Then set z = 1 + 2i and w = 2 − 3i and press z / w: the notes' answer −4/13 + 7/13 i appears.

Key facts

  • Use normal form for + and −; polar or exponential form for ·, ÷, powers and roots. [I.4]
  • Division in normal form: multiply top and bottom by the conjugate of the denominator.
  • |z|² = z·z̄, which is not z² in general: |1 + i|² = 2 but (1 + i)² = 2i.
  • Multiplying by i turns a number by 90° counterclockwise.
Part 6 · Notes I.4.2

Powers and roots: de Moivre

Raising to the k-th power raises the length to the k-th power and multiplies the angle by k. Taking an n-th root goes backwards, and because angles repeat every 2π there are exactly n different roots.

zk = rkeikφwk = n√r · ei(φ + 2kπ)/n, k = 0, …, n − 1

Drag z (powers) or w (roots); positions snap to 0.25. The view zooms to fit after each drag.

Try this. The default is the notes' example (1 + i)k for k up to 8: it ends at 16. Switch to roots and set w = 8i with n = 3: you get practice problem 10, √3 + i, −√3 + i and −2i.

Key facts

  • de Moivre: zᵏ = rᵏ(cos kφ + i sin kφ). [Cor 4.7]
  • z ≠ 0 has exactly n distinct n-th roots. They form a regular n-gon on the circle of radius ⁿ√r. [Thm 4.9]
  • The first root has angle φ/n; the others follow in steps of 2π/n.
  • The n-th roots of 1 always include 1 itself.
Part 7 · Notes II.1.4–II.1.5

Scalar product, angle and projection

The scalar product turns two vectors into one number that carries their lengths and the angle between them. Divide by the lengths and you get the cosine of the angle; zero means orthogonal. The same number gives the orthogonal projection of one vector onto the other.

⟨a, b⟩ = a1b1 + a2b2 = |a| |b| cos φab = ⟨a, b⟩ / |b|2 · b

Drag the tips of a and b (snap 0.5). The thick arrow along b is the projection of a onto b; the dashed segment from a meets b at a right angle. The shaded parallelogram has area |a₁b₂ − a₂b₁| = |a × b|, the length of the cross product when the vectors sit in ℝ³.

Try this. Set a = (2, 1) and b = (−1, 2). The scalar product is 0 and the projection shrinks to a point: orthogonal vectors. Turn on the norms: the diamond, circle and square all pass through the tip of a, but cross the axes at different distances. Three norms, three answers to “how long is a”.

Key facts

  • cos φ = ⟨x, y⟩ / (|x| |y|), with φ ∈ [0, π]. Cauchy–Schwarz guarantees this is between −1 and 1. [Thm 1.12, Def 1.13]
  • x ⊥ y means ⟨x, y⟩ = 0.
  • Norms: ‖x‖₁ = Σ|xᵢ|, ‖x‖₂ = √(Σxᵢ²), ‖x‖∞ = max|xᵢ|. Always ‖x‖∞ ≤ ‖x‖₂ ≤ ‖x‖₁.
  • |x × y| = |x| |y| sin φ is the parallelogram area; it is 0 exactly when x and y are linearly dependent. [Cor 1.19]
Part 8 · Notes II.2.2

Linear systems: geometry and the Gauss algorithm

Each equation in two unknowns is a line; solving the system means finding the common points. Two lines meet once, never (parallel) or everywhere (the same line). Ranks decide which case you are in, before you solve anything.

x + αy = 2,   2x + 4y = βThe notes' example. Subtracting twice the first row leaves (4 − 2α)y = β − 4.

Gauss elimination, step by step [II.2.2]

Shaded cells are pivots; the rows changed in this step are highlighted. Only the three allowed row operations are used (swap rows, scale a row by λ ≠ 0, add a multiple of another row), so the solution set never changes.

Try this. Set α = 2 and slide β. At every β except 4 the lines are parallel and the last row reads 0 = β − 4: a contradiction. At β = 4 the lines coincide and one unknown becomes free.

Key facts

  • Solvable exactly when rk(A | b) = rk(A). Unique when, in addition, rk(A) = n. Otherwise n − rk(A) free parameters. [Thm 2.12]
  • A row 0 … 0 | b̃ with b̃ ≠ 0 means no solution.
  • Columns without a pivot belong to the free variables; solve for the pivot variables from the bottom up.
  • A homogeneous system with fewer equations than unknowns always has non-trivial solutions.
Part 9 · Notes II.2.4–II.2.6

A matrix as a map: determinant and eigenvectors

A 2 × 2 matrix moves every point of the plane. Its columns are where the unit vectors land, the determinant is the factor by which areas change, and an eigenvector is a direction the matrix only stretches, never turns: Ax = λx.

A = (Ae1 | Ae2)pA(λ) = det(A − λI) = λ2 − Tr(A) λ + det A

A = [[a, b], [c, d]]. The two coloured arrows are the columns Ae₁ and Ae₂; the shaded parallelogram is the image of the dashed unit square, with area |det A|. Long dashed lines are the real eigenvector directions. Drag x (thin arrow); its image Ax is the thick arrow. Near an eigen direction, x snaps onto it.

Try this. With the symmetric matrix, drag x around a full circle. Only along (1, 1) and (1, −1) do x and Ax line up: there Ax = 3x and Ax = −x. Then try the rotation: no real direction survives, and the eigenvalues turn complex.

Key facts

  • The columns of the matrix are the images of the unit vectors. [Thm 2.37]
  • det A = 0 ⇔ not invertible ⇔ the plane collapses onto a line (or a point) ⇔ 0 is an eigenvalue. [Thm 2.28, 2.44]
  • Tr A = λ₁ + λ₂ and det A = λ₁λ₂: a quick check on any eigenvalue computation.
  • Diagonalizable ⇔ algebraic = geometric multiplicity for every eigenvalue. Symmetric matrices always are, with orthogonal eigenvectors. [Thm 2.50]
Part 10 · Notes II.2.7

Least squares: the best line through noisy points

With more points than parameters, no line passes through all of them. Least squares picks the line that makes the sum of squared vertical errors smallest. Here the squares are drawn literally: the best fit minimises their total area.

ATA x* = ATbFor a line y = a₀ + a₁x, row i of A is (1, xᵢ) and b holds the yᵢ. For a parabola, add a column xᵢ².

Drag the points (snap 0.25). Vertical segments are the residuals rᵢ = yᵢ − p(xᵢ); each square has side |rᵢ|. In hand mode the dashed curve is the best fit for comparison.

Try this. With the notes' three points, step through P₀, P₁ and P₂. The errors shrink from √2 to √6/2 to 0: a parabola has three parameters, so it can pass through three points exactly. Then fit the line by hand and try to beat the computed one. You can't.

Key facts

  • The normal equations always have a solution; it is unique exactly when rk(A) = n. [Thm 2.53]
  • At the optimum the residual r = Ax* − b is orthogonal to Im(A).
  • AᵀA is always square (n × n), however many data points there are.
  • Through the origin only (Ohm's law U = RI): R* = Σ UᵢIᵢ / Σ Iᵢ².
Check · Whole course

Check your reasoning

Commit to an answer before opening each one. Most can be checked on a bench above.

1. Is “if 2 = 1, then 0 = 0” a true statement?

Yes. A ⇒ B is false only when A is true and B is false. Here A is false, so the implication is true whatever B says. The notes even derive 0 = 0 from 2 = 1 by multiplying both sides by 0. Part 1, row A = 0, B = 1.

2. Solve |3 − x| ≥ 2.

|3 − x| = |x − 3|, the distance from x to 3. At least 2 away: x ≤ 1 or x ≥ 5, i.e. (−∞, 1] ∪ [5, ∞). In Part 2 set m = −1, c = 3, r = 2 and choose “≥”.

3. Where exactly does the proof of Bernoulli's inequality use x ≥ −1?

In the step: (1 + x)n+1 = (1 + x)(1 + x)n ≥ (1 + x)(1 + nx). Multiplying the hypothesis by 1 + x keeps “≥” only if 1 + x ≥ 0. The second estimate, dropping nx² ≥ 0, works for every x.

4. Does f(x) = x² with f : [0, ∞) → ℝ have an inverse?

It is injective (strictly increasing) but not surjective: no x gives −1. So f : [0, ∞) → ℝ is not bijective. The inverse √y exists for the restriction f : [0, ∞) → [0, ∞), or, as the notes put it, from W(f) back to D(f).

5. What is arg(−1 − i)?

a = −1 < 0, so φ = arctan(b/a) + π = arctan(1) + π = π/4 + π = 5π/4. arctan(b/a) alone gives π/4, which points into the first quadrant: the opposite direction.

6. Without computing, how far apart are the 6th roots of any z ≠ 0?

They sit on a circle of radius ⁶√|z|, spaced 2π/6 = π/3 = 60° apart: the corners of a regular hexagon. Only the starting angle φ/6 depends on arg z.

7. a = (3, 4), b = (4, −3). What are ⟨a, b⟩ and the area of their parallelogram?

⟨a, b⟩ = 12 − 12 = 0, so they are orthogonal. Then the parallelogram is a rectangle with area |a| |b| = 5 · 5 = 25, which matches |a₁b₂ − a₂b₁| = |−9 − 16| = 25.

8. For which α and β has x + αy = 2, 2x + 4y = β infinitely many solutions?

Elimination leaves (4 − 2α)y = β − 4. Infinitely many solutions need 0 = 0, so α = 2 and β = 4: then y = λ, x = 2 − 2λ. For α = 2 and β ≠ 4 there is none; for α ≠ 2 exactly one.

9. Is A = [[2, 1], [0, 2]] diagonalizable?

No. λ = 2 is a double root (algebraic multiplicity 2), but (A − 2I)x = 0 only allows multiples of (1, 0): geometric multiplicity 1. One eigen direction is not enough for a basis. Part 9, “Not diagonalizable”.

10. Why does the least-squares parabola through three points have zero error?

With three points and three unknowns a₀, a₁, a₂, the system Ax = b is square and (for distinct xᵢ) uniquely solvable. Its exact solution makes the residual 0, and nothing can beat 0, so the normal equations return it.
