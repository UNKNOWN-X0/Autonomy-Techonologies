Logic and sets

A statement is a sentence that is either true (1) or false (0). Compound statements are evaluated with a truth table.

Key facts.

  • ∨\vee∨ is inclusive (“or both”), not “either … or”.

  • A⇒BA\Rightarrow BA⇒B is false only when AAA is true and BBB is false. Rewrite: (A⇒B)⇔(¬A∨B)(A\Rightarrow B)\Leftrightarrow(\neg A\vee B)(A⇒B)⇔(¬A∨B).

  • A tautology is always true regardless of inputs; check by truth table.

  • De Morgan: ¬(A∧B)⇔¬A∨¬B\neg(A\wedge B)\Leftrightarrow \neg A\vee\neg B¬(A∧B)⇔¬A∨¬B and ¬(A∨B)⇔¬A∧¬B\neg(A\vee B)\Leftrightarrow\neg A\wedge\neg B¬(A∨B)⇔¬A∧¬B.

  • Proof by contradiction uses (A⇒B)⇔¬(A∧¬B)(A\Rightarrow B)\Leftrightarrow\neg(A\wedge\neg B)(A⇒B)⇔¬(A∧¬B).

Quantifiers.

∀\forall∀ (for all), ∃\exists∃ (there exists), ∃!\exists!∃! (exactly one). To negate, swap ∀↔∃\forall\leftrightarrow\exists∀↔∃ and negate the inside:

Gauss algorithm

Allowed row operations: swap rows, multiply a row by λ≠0\lambda\ne0λ=0, add a multiple of one row to another.

  1. Forward elimination: bring (A ∣ b)(A\,|\,b)(A∣b) to row echelon form.

  3. Back substitution: non-pivot columns are free variables; solve for pivot variables bottom-up.
